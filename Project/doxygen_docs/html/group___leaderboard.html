◆ leaderboard_add_score()

void leaderboard_add_score ( const char * username,
int score,
int progress,
int song_id,
rtc_timestamp current_time )

Adiciona uma nova pontuação à leaderboard.

Caso a pontuação seja suficientemente alta, insere a entrada na posição correta, ordenando a leaderboard e descartando pontuações mais baixas se exceder o MAX_SCORES.

Parâmetros
usernameNome do jogador.
scorePontuação final obtida.
progressProgresso concluído da música.
song_idIdentificador da música.
current_timeTimestamp do RTC do momento em que o jogo acabou.
