◆ update_notes()

int update_notes ( )

Atualiza a posição de todas as notas ativas.

Faz as notas descerem no ecrã de acordo com a sua velocidade. Também verifica se alguma nota passou a HIT_ZONE sem ser tocada, contabilizando como um "miss".

Retorna
int Número de notas que passaram o limite inferior (misses) neste frame.
