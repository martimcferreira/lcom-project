◆ beatmap_load()

int beatmap_load ( const char * path,
BeatmapEntry * out_notes,
int * out_count )

Carrega um beatmap a partir de um ficheiro de texto.

Lê um ficheiro de texto (onde cada linha válida contém o tick e a pista) e preenche o array passado como argumento, para ser depois processado ao longo do jogo.

Parâmetros
pathCaminho absoluto para o ficheiro .txt com o mapa.
out_notesArray destino que armazenará a sequência de notas (deve suportar BEATMAP_MAX_NOTES).
out_countApontador onde será guardado o número total de notas lidas com sucesso.
Retorna
int Retorna 0 em caso de sucesso, ou não-zero caso o ficheiro não exista ou tenha formato inválido.
