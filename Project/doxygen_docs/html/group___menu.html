◆ GameState

enum GameState

Enumeração global que define a Máquina de Estados principal do jogo.

Valores de enumerações
MENU 

Ecrã do Menu Principal.

USERNAME_ENTRY 

Ecrã de inserção do nome de utilizador.

SONG_SELECT 

Ecrã de seleção da música a jogar.

PLAY 

Gameplay ativo.

PAUSE 

Jogo em pausa.

GAME_OVER 

Ecrã de Game Over (vida chegou a 0).

GAME_WON 

Ecrã de Vitória (música chegou ao fim).

LEADERBOARD 

Ecrã da Leaderboard (Top 5 Heroes).

◆ MenuInputMode

enum MenuInputMode

Enumeração para definir qual o periférico que está a controlar os menus no momento.

Valores de enumerações
MENU_INPUT_KEYBOARD 

O menu está a ser navegado através do Teclado (setas).

MENU_INPUT_MOUSE 

O menu está a ser navegado através do Rato.

bool left_click,

Verifica interações e cliques no Menu Principal.

Parâmetros
mouse_xCoordenada X onde ocorreu a interação (ou a posição do teclado focada).
mouse_yCoordenada Y onde ocorreu a interação.
left_clicktrue se o utilizador premiu um botão de aceitar (clique esquerdo ou Enter).
current_stateApontador para a máquina de estados global (é alterada consoante a seleção).
game_runningApontador para a variável de loop do LCOM (colocada a false se selecionado 'Sair').
